# 한국 어문회 기준 한자능력검정시험 (8급~6급) 학습 웹 애플리케이션 (PWA)

> **"Clean Pure White & Translucent Colorful Gradient Ribbon"** (소프트 뉴모피즘 + 글래스모피즘 테마)
> 아이패드(Apple Pencil 완벽 대응), 아이폰, PC 브라우저 지원 크로스 플랫폼 에듀테크 PWA.

---

## 🎨 1. 디자인 시스템 & UX/UI 핵심 스타일
- **Pure White & Soft Elevation**: 순백색(`#FFFFFF`) 컨테이너, 둥근 모서리(`border-radius: 24px`), 부드러운 확산 그림자(`box-shadow: 0 10px 25px -5px rgba(0,0,0,0.05)`).
- **Translucent 3D Gradient Ribbon SVG Icons**:
  - 📖 **공부 모드**: 오렌지-코랄 그라데이션 (`#FF9A44` ➔ `#FC6076`)
  - 🗂️ **플래시카드**: 퍼플-핑크-블루 그라데이션 (`#B721FF` ➔ `#21D4FD`)
  - 📝 **모의시험**: 에메랄드-민트-블루 그라데이션 (`#00F2FE` ➔ `#4FACFE`)
  - 📊 **성장 리포트**: 시안-인디고 그라데이션 (`#30CFD0` ➔ `#5B247A`)
  - ⚙️ **설정 & AI**: 라임-그린 그라데이션 (`#A8EB12` ➔ `#00BF72`)
- **타이포그래피**: 고품질 산세리프 및 학습용 한자 명조/해서체(`Noto Serif KR`)와 고딕체 실시간 토글 지원.

---

## 📱 2. 플랫폼 및 Apple Pencil / 터치 필기 최적화
- **HTML5 `<canvas>` + `Pointer Events API`**: 애플펜슬 필압 감지 및 부드러운 Bezier 곡선 보간 필기 엔진.
- **제스처 충돌 방지**: `touch-action: none` 및 이벤트 차단으로 아이패드/아이폰에서 필기 중 화면 스크롤이나 확대/축소 완벽 방지.
- **필기 도구 모음**: 먹물 블랙, 로얄 블루, 주홍 레드, 다이내믹 그라데이션 잉크, 펜 굵기 3단계(3px / 6px / 11px), 米자격/十자격 보조선 가이드, 실행취소(Undo), 지우개, 전체 지우기.

---

## 👥 3. 멀티 유저 & 급수 관리 시스템
- **다중 사용자 프로필**: 이름, 그라데이션 아바타, 목표 급수 설정. 헤더에서 원클릭으로 전환 가능.
- **완전 분리 저장**: `LocalStorage` 기반으로 유저별 학습 진도, 플래시카드 간격 반복 큐, 모의고사 성적표, 오답노트가 완전히 독립 보관됨.
- **한국 어문회 배정한자 탑재**:
  - **8급**: 기초 50자
  - **7급 II**: 50자 추가 (누적 100자)
  - **7급**: 50자 추가 (누적 150자)
  - **6급 II**: 75자 추가 (누적 225자)
  - **6급**: 75자 추가 (누적 300자)
  - 각 한자별 `{ id, level, kanji, hun, eum, radical, strokeCount, exampleWords }` 완전 수록.

## ☁️ 4. Firebase Authentication & Firestorage 멀티 디바이스 동기화
- **이메일(ID) / 비밀번호(PW) 회원가입 & 로그인**:
  - 상단 헤더의 `☁️ 동기화` 버튼 또는 설정 탭에서 원클릭으로 로그인/가입.
  - 가입/로그인 완료 시 헤더에 실시간 연결 상태 배지(`user@email.com`, 그린 펄스 점) 표시.
- **스마트폰 • 아이패드 • PC 브라우저 실시간 동기화**:
  - **Firestorage (`users/{uid}/hanja_study_data.json`)** 기반으로 학습 진도, Anki 카드 복습 주기, 모의고사 성적표, 오답노트를 클라우드에 자동 백업.
  - Firestore 및 Realtime Database 멀티 백엔드 폴백 지원으로 환경 제약 없이 완벽 작동.
  - **백그라운드 자동 동기화**: 한자를 학습하거나 플래시카드를 복습할 때 디바운스(Debounce) 자동 클라우드 저장.
  - 새 기기에서 로그인 시 클라우드의 최신 학습 상태를 즉시 복원하여 어디서든 끊김 없이 이어서 학습 가능.

## 🌟 5. 5개 메인 탭 상세 기능

### Tab 1. 공부 모드 (순차 학습 & 획순 연습)
- **HanziWriter 연동**: 1) 획순 애니메이션 자동 재생, 2) 획순 따라쓰기 교정 퀴즈 모드.
- **자유 반복 쓰기 캔버스**: 3회 / 5회 / 10회 목표 반복 횟수 설정. 1회 쓸 때마다 카운트되며 목표를 채우면 폭죽 애니메이션과 함께 학습 완료 처리 및 다음 한자로 자동 이동.
- **[💡 AI 연상 암기 팁]**: 부수와 글자 분해를 통한 기발하고 재미있는 연상 스토리텔링 생성.

### Tab 2. 플래시카드 모드 (Anki SM-2 Spaced Repetition + 필기 자가 검증)
- **출제 방향 2종**: `[한자 ➔ 뜻/음 맞히기]` / `[뜻/음 ➔ 한자 쓰기]`.
- **필기 자가 검증**: 캔버스에 직접 쓴 글씨와 [정답 확인]을 눌렀을 때 표시되는 실제 한자/훈음을 나란히 비교.
- **Anki SM-2 알고리즘**:
  - `다시(Again)`: 오답노트 직행, 1분 뒤 재출제
  - `어려움(Hard)`: 복습 주기 x1.2
  - `알맞음(Good)`: 복습 주기 x2.5
  - `쉬움(Easy)`: 복습 주기 x4.0

### Tab 3. 모의시험 모드 (실전 한자능력검정시험)
- **출제 옵션**: 급수 선택, 10/20/50문항, 제한시간 타이머.
- **문제 유형 혼합**: 독음 고르기, 훈음 고르기, 뜻에 알맞은 한자 고르기, 주관식 손글씨 직접 쓰기 (자가채점형).
- **시험 결과 및 총평**: 총점 환산, 80점 이상 합격 안내, 오답노트 자동 등록, **[Gemini AI 실전 시험 총평 & 처방전]** 원클릭 생성.

### Tab 4. 리포트 & 대시보드
- **Daily 학습 현황**: 일별 학습량, 플래시카드 복습 수, 연속 학습일(Streak 🔥) 카운터.
- **성적 향상 그래프**: `Chart.js` 기반 회차별 모의시험 점수 변동 추이 라인 차트 및 급수 완성도 프로그레스 바.
- **취약 한자 (오답 노트)**: 오답 빈도순 정렬, `[🔥 취약 한자만 집중 복습]` 및 `[🤖 AI 취약 한자 맞춤 코칭]`.

### Tab 5. 설정 및 AI 어시스턴트 (Gemini API Fallback 시스템)
- **4단계 자동 폴백(Fallback) 라우터**:
  1. `gemini-3.8-flash`
  2. `gemini-3.6-flash`
  3. `gemini-3.5-flash`
  4. `gemini-2.5-flash`
  - 할당량 초과(429), 모델 없음(404), 5xx 서버 오류 시 중단 없이 다음 모델로 자동 전환.
- **데이터 백업 & 복원**: 전체 사용자 데이터를 안전하게 JSON 파일로 내보내기/가져오기.

## 🚀 6. 실행 및 PWA 설치 방법

### 가장 간편한 실행 방법 (Windows)
프로젝트 폴더 안의 **`start_app.bat`** 파일을 더블 클릭하기만 하면 로컬 서버 구동과 함께 브라우저가 자동 실행됩니다.

또는 터미널에서 다음 명령어를 실행합니다:
```bash
node server.js
```

### 접속 및 기기별 PWA 설치 방법
* **PC 브라우저**: `http://localhost:8080` 접속 (Chrome/Edge 주소창 우측 **[앱 설치]** 클릭)
* **아이패드 / 스마트폰**: 동일 Wi-Fi에 연결 후 터미널에 표시된 IP 주소(예: `http://192.168.0.7:8080`)로 접속
  * **iPad / iPhone Safari**: 하단 공유 버튼 ➔ **"홈 화면에 추가"** ➔ 전체화면 네이티브 PWA 앱으로 사용 가능!
